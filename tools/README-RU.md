## menu

Единая точка входа в экосистему.

Устал авторизовываться в каждом приложении отдельно. Раз всё это части одной
экосистемы, то и переходы между ними должны быть бесшовными. А ещё мне надоело
вводить адреса в браузер — удобнее собрать все приложения в одном месте и
попадать в menu из любого из них.

## Что внутри

- **SSO между приложениями** — вошли один раз, и сессия переходит вместе с вами, без повторной авторизации
- **Все сервисы под рукой** — каждое приложение в один клик, и из любого можно вернуться в menu
- **Проверка доступности** — menu следит за приложениями и не пустит в сервис, который сейчас лежит
- **Информационный центр** — всё об экосистеме в одном месте
